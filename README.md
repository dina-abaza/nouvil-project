# **Mouse-Movement Boat Animation**

This is a simple **CSS-only** animation project where a boat image moves over a sea image based on the mouse movement. The boat's position changes as the mouse moves around the screen, creating an interactive effect using only **HTML** and **CSS**.

---

## **Features**:

- **Interactive Animation**: The boat moves smoothly across the sea when the user moves the mouse.
- **CSS-only**: The animation is achieved without the need for JavaScript, using only CSS `position`, `transform`, and `transition` properties.
- **Responsive Design**: The application adjusts its layout to fit different screen sizes.
- **Smooth Transition**: The movement of the boat is smooth and reacts quickly to the user's mouse position.

---

## **How It Works**:

1. The boat image is initially positioned over the sea image using **CSS positioning**.
2. Using **CSS hover** and **transform** properties, the boat follows the mouse movement across the screen when the user moves the mouse.
3. The boat is visually positioned over the sea, and it moves in relation to the mouse position to give the effect of sailing across the sea.

---

## **Technologies Used**:

- **HTML**: For the structure of the webpage (boat, sea images, etc.).
- **CSS**: For styling the boat, sea, and the animation effect using mouse movement.
